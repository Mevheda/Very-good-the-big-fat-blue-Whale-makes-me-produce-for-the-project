# Answer Style

## Goal

Write answers that read like a student explaining the idea in their own words.

The answer must remain technically correct. The difference is in expression: less like a textbook entry, more like a concise spoken explanation that has been written down.

## Use

- Short, natural sentences;
- common course terminology, explained where useful;
- moderate first-person framing such as “可以理解为”, “简单说”, or “我觉得这里主要是在说”;
- direct answers that stay close to the question;
- varying paragraph lengths;
- examples only when they clarify the concept.

## Avoid

- Copying textbook sentences nearly word for word;
- writing every answer as a complete encyclopedia entry;
- making every answer use the same “首先、其次、最后” structure;
- long symmetrical lists with several abstract nouns in each item;
- stock phrases such as “综上所述”“具有重要意义”“为……提供了坚实保障” when they add no meaning;
- invented personal experiences, fake observations, or unsupported examples;
- deliberate grammar mistakes, typos, slang, or lowered technical accuracy.

## Correctness boundary

Natural wording never permits factual errors. Keep definitions, distinctions, conditions, and conclusions correct. If a concept is uncertain, verify it instead of making the answer sound casual.

## Example

Textbook-like:

> 数据模型是对现实世界中数据特征、数据联系以及相关约束的抽象和表示，是数据库系统中用于描述、组织和处理数据的工具。

Natural paraphrase:

> 可以先把数据模型理解成对现实世界数据的一种简化描述。它主要说明数据库里有哪些数据、这些数据之间有什么关系，以及能对它们做哪些操作。

Both are correct. The second version reads more like an explanation written by a student.
